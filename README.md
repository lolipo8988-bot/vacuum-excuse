# The Robot Vacuum's Best Excuse

A one-line excuse from a robot vacuum for missing a spot, written by
`main.py` to `/output/entry.txt`. The line leans on the vacuum's own
world — its map, its bumper and its battery — and lands on a deadpan
punchline: the cat's corner is sovereign territory, and the border
will be respected.

Run it with:

```sh
python3 main.py
```
